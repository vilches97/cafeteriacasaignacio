# Cafetería Casa Ignacio

Sitio web para Cafetería Casa Ignacio, una cafetería tradicional en Martos (Jaén) especializada en desayunos.

## Características

- Menú de desayunos tradicionales
- Información de contacto y horarios
- Diseño responsivo
- Optimizado para SEO

## Tecnologías

- React 18
- TypeScript
- Tailwind CSS
- Vite
